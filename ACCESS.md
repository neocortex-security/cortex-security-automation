# Access to the full tooling

This repository is a **preview**: documentation, architecture, sample output and
results. The source code, schemas, rule libraries and operational documentation live in
a private repository.


## Who can get access

This tooling was built in the course of Palo Alto Networks Professional Services
engagements. The full tooling is made available to organisations working with me on a
Cortex Cloud deployment or a Prisma Cloud → Cortex Cloud migration.

To request access, contact me directly — see below.

Access is granted per organisation, to named GitHub accounts, for the duration of the
engagement and an agreed support period.

## What you get

- Read access to the private repository (source, schemas, rule libraries, runbooks)
- Signed binaries for macOS (arm64) and Linux (x86_64) where the tool ships as one,
  with an installation guide per platform
- The migration guides (process, files, flags, measured platform limits, checklists)
  where the tool is part of a migration
- Release notes and upgrade guidance for each version
- A named contact for defects found during the engagement

## What is **not** included

- Redistribution rights — access is for your organisation's own use
- Support for environments outside the engagement scope
- Any Palo Alto Networks product licence; you need your own Cortex Cloud / Prisma Cloud
  tenant and API credentials

## How to ask

Open an issue using the **Access request** template (preferred — it asks for the few
facts I need), or email **<<YOUR CONTACT EMAIL>>** with:

1. Organisation and your role
2. Which tool(s) and the engagement or migration they are for
3. GitHub usernames to be granted access
4. Target platforms (macOS / Linux) if you need binaries

Expect a reply within **7 working days**.
